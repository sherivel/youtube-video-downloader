# 🎥 YouTube Video Downloader

A simple and fast desktop application built with Python that allows you to download YouTube videos directly to your computer with a single click.

## ✨ Features
- **A Graphical Interface:** A visual app window with interactive text inputs and download buttons.
- **Universal Format:** Automatically downloads files as **MP4 (H.264 video + M4A audio)**, meaning the files are compatible with Mac's QuickTime Player and Windows Media Player without crashes.
- **Direct to Desktop:** Automatically saves the completed video file straight to your computer's Desktop for easy access.

## 💻 How to Run It on Your Computer

### 1. Download the Code
Download both `youtube-video-downloader-code.py` and `requirements.txt` into the same folder on your computer.

### 2. Install Dependencies
Open your computer's terminal or your coding platform, change directories to this project folder, and run the following command to download the libraries:
```bash
pip install -r requirements.txt
```

### 3. Run the App
Launch the interface by running the script:
```bash
python youtube-downloader-code.py
```
Paste any YouTube link into the box, click **Download Video**, and check your Desktop for the file when it's done.
